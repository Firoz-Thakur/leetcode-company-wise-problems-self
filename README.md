# leetcode-company-wise-problems-self

My personal collection of company-wise LeetCode problems, solutions, and notes for coding interview preparation.

## Goals

- Practice problems commonly associated with different companies.
- Strengthen data structures and algorithms fundamentals.
- Record approaches, time and space complexity, and lessons learned.
- Revisit challenging problems and track progress over time.

## Suggested organization

Group solutions by company, then use a descriptive filename for each problem. For each solution, include:

- A link to the LeetCode problem.
- The main idea behind the approach.
- Time and space complexity.
- Important edge cases.

## Practice plan

1. Pick a company and a problem to practice.
2. Try solving it independently before checking hints.
3. Test the solution with examples and edge cases.
4. Save the solution and a short explanation.
5. Return to difficult problems regularly.

Company associations can change over time; use these problems as practice material rather than a guarantee of interview questions.
